# 文档与交付参考

用于判断变更影响和选择交付验证范围。目标仓库可能使用不同文档站点、API 生成工具、构建脚本或质量门禁；先从 Agent 指令、README、CI、package/Maven 配置和现有文档流程中查找。

## 变更影响

根据改动检查是否需要同步：

- API 路径、请求/响应字段、权限或错误语义：API 参考、客户端类型和调用方。
- 表、字段、约束、索引、迁移或数据回填：Schema/实体文档和运维迁移说明。
- 新增、删除或修改配置项、环境变量和依赖：配置清单、示例配置及升级说明；示例不得含真实凭据。
- 新增/升级依赖或版本基线变化：[version-baseline.md](version-baseline.md)、升级说明与兼容性/漏洞核对。
- 新增模块、服务边界、路由或关键流程：架构导航、开发说明和相关用户文档。
- 影响部署、备份、恢复或排障的行为：部署和运维文档。

只更新确实受影响的文档；避免复制同一事实到多个不一致的位置。若项目使用自动生成文档，先确认源文件和生成流程，不手工编辑生成物。

## 交付核对

1. 查看目标项目规定的格式、静态分析、类型检查、测试和构建入口，选择适合本次范围的检查。
2. 对跨前后端契约变更，核对服务端定义、客户端类型与调用方一致，并确认字段使用 `snake_case`、响应为 `{code,message,data}` 统一壳、`code` 与 HTTP 状态一致、分页为 MyBatis-Plus `Page`。
3. 对新增/修改端点，核对状态码符合标准表（成功 `200`/`201`、无内容 `204`、错误 `400`/`401`/`403`/`404`/`409`/`500`），错误响应带 body。
4. 对新增/修改的公开 API、导出函数、表或列，核对注释符合 [comments.md](comments.md)：L1/L2 必须、实现类不重复接口 Javadoc、数据库表与所有列有 `COMMENT`。
5. 对序列化改动，核对 `snake_case`、Long/BigInteger 字符串化、时间格式与时区、枚举输出、`null` 与集合的输出契约。
6. 对持久化/安全改动，核对 MyBatis-Plus 插件（分页、乐观锁、逻辑删除、自动填充、防全表）与密码存储（`PasswordEncoder`）符合标准。
7. 对可观测性改动，核对 traceId/MDC 透传与 Actuator 端点暴露范围。
8. 对新增/升级依赖或版本变化，核对 [version-baseline.md](version-baseline.md) 与兼容性、漏洞扫描结果。
9. 对数据库变更，核对迁移命名与顺序、旧数据处理、部署兼容性和恢复策略；迁移机制默认为 Flyway。
10. 对 Redis 或认证行为变更，核对异常、超时、重试和安全状态不确定时的预期结果，以及 UUID token 会话的 TTL 与失效。
11. 对前端交付，核对 mock 未进入生产构建、错误监控与 sourcemap 配置正确。
12. 检查差异没有意外修改、明文凭据、调试数据或本机配置。
13. 汇报实际执行的检查及结果；未执行的检查不要声称通过。

## Definition of Done

声明任务完成前逐项确认（按改动范围取用）：

- [ ] 格式、静态分析、类型检查已通过（后端与前端各自的门禁）。
- [ ] 相关测试通过；新增/修改逻辑有覆盖，回归缺陷有可复现测试。
- [ ] 新增/修改的迁移可安全执行且可回滚，顺序与兼容性已验证。
- [ ] API 契约（路径、字段、状态码、统一壳、序列化）与前端类型、调用方、接口文档一致。
- [ ] 公开 API、导出函数、表与列的注释符合 [comments.md](comments.md)。
- [ ] 认证/授权、输入校验、数据范围已核对；无明文凭据、无敏感信息进日志或前端包。
- [ ] 统一异常处理包含兜底处理器，未预期异常对外只返回 `500`，不泄露堆栈与内部细节。
- [ ] 时间字段区分绝对时刻与本地语义，响应带偏移或统一 UTC，且不存在无偏移的本地时间返回。
- [ ] 序列化按 Jackson 3 配置；如启用虚拟线程，已核对上下文传播、线程池与连接池；软删除表的唯一约束为部分唯一索引。
- [ ] 配置/环境变量变更已同步示例与文档，`.env` 不含真实密钥；敏感文件已纳入 `.gitignore` 未入库。
- [ ] 新增/升级的依赖已核对 [version-baseline.md](version-baseline.md) 与兼容性并做漏洞扫描；废弃 API 已按公告窗口处理。
- [ ] 变更影响已核对：路由/权限、i18n、mock、部署与运维文档。
- [ ] 未执行的检查已如实说明，未声称通过。

不要从参考示例推导目标项目的命令。自动格式化、数据库操作、部署、发布和推送应遵守项目规定及当前用户授权。
